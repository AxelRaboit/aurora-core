# Glossaire de Studio

Un mot par notion, le même partout : dans le menu, les titres, les boutons, les
guides « Comment ça marche », les emails, les pages que lit le client, en
français, en anglais et en espagnol. Fixé le 06/10/2026 après l'audit de Studio,
avec Axel.

**Pourquoi un glossaire.** L'audit a trouvé cinq noms pour un même élément du
tableau, quatre pour une demande de modification, et des écrans où le studio et
le client ne nommaient pas la même chose du même mot. Un lecteur qui voit deux
mots croit qu'il y a deux choses. Avant d'écrire un libellé de Studio, on
cherche le mot ici ; s'il manque, on l'ajoute ici d'abord.

Les colonnes : le mot français, l'anglais, l'espagnol, puis ce qu'il ne faut
plus écrire.

Notes, on écrit toujours « espace de notes ».

## Les états et les gestes

| Notion | fr | en | es | À ne plus écrire |
|---|---|---|---|---|
| Le client demande une modification | à revoir | changes requested | por revisar | modification demandée, à reprendre, reprise |
| Le client valide | validé | approved | validado | |
| Les rôles d'étape | Relecture, Publié | Review, Published | Revisión, Publicado | Idée, Production, Programmé (retirés) |
| Ce qui attend la réponse du client | chez le client | with the client | con el cliente | |
| L'état d'une trame | brouillon, en vigueur, remplacée, archivée | draft, in force, superseded, archived | borrador, vigente, sustituida, archivada | publiée |
| Un contrat signé des deux côtés | conclu | concluded | concluido | |
| Rendre visible au client | montrer au client / cacher au client | show to the client / hide from the client | mostrar al cliente / ocultar al cliente | ouvrir, retirer, ouvrir au client |
| L'état correspondant | visible par le client | visible to the client | visible para el cliente | |
| Rayon d'un livrable de Studio | perso, partagé | personal, shared | personal, compartido | personnel, partagé avec l'équipe |
| Une adresse qui ouvre un livrable sans compte | lien de lecture (bouton « Partager ») | reading link (« Share ») | enlace de lectura (« Compartir ») | lien de partage |
| Une adresse qui ouvre un espace au client | lien d'accès | access link | enlace de acceso | |

**Visibilité.** Un élément neuf est caché au client ; le montrer (ou le
cacher) demande le droit « partager » de l'espace, le même que donner un lien
d'accès. Vaut pour les étapes, les ressources, les livrables, les canaux et les
fichiers d'un espace (règle dans `ClientVisibility`). Trois exceptions,
voulues : un espace neuf montre ses étapes Relecture et Publié, le canal
« Général » est toujours montré, et un fichier envoyé par le client reste
visible pour lui. Les notes ne sont jamais montrées.

## Les boutons de création

Toujours « Nouveau … » ou « Nouvelle … », dans le menu comme dans le titre de la
fenêtre : « Nouveau contrat », « Nouvelle trame », « Nouveau livrable »,
« Nouveau contenu », « Nouvelle ressource ». Jamais « Ajouter un … », « Créer
un … » ni « Préparer un … ». En anglais « New … », en espagnol « Nuevo … » /
« Nueva … ».
